# Budget-Constrained Search

Budget = MAXIMUM NUMBER OF EXPENSIVE CANDIDATE EVALUATIONS.
Explicit budgets: 10, 25, 50, 100.

## Exploration vs Exploitation
Under budget B, allocate:
- High-confidence exploitation
- Uncertainty-driven exploration
- Limited random exploration
(Proportions must be configurable).

## Baselines
- Method A: Random / Uninformed Search
- Method B: Global Experience
- Method C: Context-Aware Transfer
- Method D: Full CAFET
- Method E: Exhaustive Reference (approximate ceiling)
