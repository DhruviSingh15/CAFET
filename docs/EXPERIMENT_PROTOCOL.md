# Experiment Protocol

## Design
- Evaluate using multiple seeds (at least 5 for final benchmark).
- Methods: Random, Global Experience, Context-Aware Transfer, Full CAFET, Exhaustive Reference.
- Budgets: 10, 25, 50, 100.

## Fairness Constraints
- Same Candidate Universe
- Same Evaluation Budget
- Same Downstream Model
- Same Train/Validation/Test Protocol
- Same Preprocessing
- Only candidate prioritization should differ.
